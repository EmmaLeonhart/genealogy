# Distant pairs — where to ask Geni for a path

Generated by `genimerge.distant` — re-run `python -m genimerge distant`.

Each row is two people our tree connects only by a long walk. **Geni very likely connects them by a shorter one**, and the people on that shorter route are ones we do not hold — so the relationship path between a pair is a prediction about a community missing from our data, and saving that page is how to test it.

## How this was measured

Distance is hops over parent/child *and* spouse edges, undirected, so a hop crosses a marriage as readily as a birth. The endpoints come from an approximate diameter (double-sweep BFS) with each pair seeded from a different far node, so these are ten different corners rather than ten names off one branch. Redacted `Private` profiles are skipped: the point is to open both people on Geni and read the path.
