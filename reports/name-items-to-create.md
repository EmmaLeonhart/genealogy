# Name items: which exist, which would have to be created

Emma, 2026-08-12: *"I probably want you to do some analysis right now of which
names could have objects created for them that do not have those objects right
now."*

**A name is not a label.** This is about the *items* `P735` and `P734` point at.

Strings that are not names are excluded before counting — regnal ordinals,
`NN`, `N.N.`, bare particles, punctuation. Every one of those was in the
measured unresolved head of `reports/name-resolution.md`, where they dragged the
resolution rate down without any real name having failed.

## The limit of this measure

The lookup is built from name items **our own people already point at**. A name
Wikidata has an item for, which nobody in our store references, reads here as
*no item*. So the "could be created" column is an **upper bound** — some of it
is names that need finding, not creating, and telling those apart needs a
download wider than the family walk.
