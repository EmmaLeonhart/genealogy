geni

Merge every Geni.com GEDCOM export into one genealogy, reconcile it against Wikidata, and generate the edits that create the people Wikidata is missing. The Geni profile ID is the primary key throughout, so joining is exact rather than fuzzy name matching.

How a person is modelled

A person

P31 Q5 human, P21 sex or gender, P2600 Geni.com profile ID with P1810 subject named as as a qualifier carrying what Geni renders.

A name

P735 given name and P734 family name point at name ITEMS, ordered by P1545 series ordinal. The first given name carries P7452 → Q3409033 usual forename; a middle name carries P3831 → Q245025.

A patronymic

P5056 patronym or matronym — its own property, parallel to P735, never a qualifier on one. It carries P144 based on pointing at the PERSON that link names: the father, then the grandfather for a chained patronymic.

A date

A GEDCOM modifier becomes a qualifier. ABT/EST/CAL → P1480 sourcing circumstances = Q5727902 circa; BEF → P1326 latest date; AFT → P1319 earliest date; BET x AND y → both.

The label

mul is the real label and carries the MARRIED name; the birth name is an Amul alias. No Aen is ever added, and no descriptions go on people.

A redacted person

The person is created and the structure kept — Geni ID, sex, parents, children, dates — but Private never becomes a label. An unnamed person keeps the NN marker in mul and gains a descriptive label in other languages.
