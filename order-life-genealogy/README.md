# order.life genealogy

The genealogy material from order.life (submodule `order.life/`, `master`), moved here 2026-09-30.

- `persons.tsv`, `edges.tsv`, `spouses.tsv`: order.life's own extracts from `wikibase/analysis/`
  (106,746 people; 60,074 with a Wikidata QID, 35,009 with a Geni id; 128,413 parent links;
  24,741 spouse pairs).
- `order-life-gaiad-2026-09-30.ged`: the same, exported by order.life's
  `wiki-scripts/export_gedcom.py` (106,883 individuals, 56,865 families).

It is the Gaiad's synoptic genealogy, so it includes mythic people and divine fathers. It is NOT in
`exports/` and is not merged into the synoptic tree; whether and how it joins is Emma's decision.
